🌙 Kido Clock - web installer

Flash the Kido Clock firmware to an ESP32-C3 SuperMini straight from the browser. Use Chrome or Edge on a desktop (Web Serial is required).

  1. Plug the board in with a USB-C data cable.
  2. Click the button below and pick the board's serial port.
  3. If the board is not detected: hold BOOT, tap RST, release BOOT, then try again.

After flashing, connect to the Wi-Fi network Kido-Clock-Setup to set up Wi-Fi and choose the clock's language, then open http://kido-clock.local.

Updating from 1.0.x? Version 1.1 uses a new partition layout (no OTA, room for colour icons), so the daily plan and the saved Wi-Fi network are reset once. Save your plan first from http://kido-clock.local/api/config if you want to re-create it.

This page must be served over HTTPS (for example GitHub Pages) with manifest.json and kido-clock-esp32c3-merged.bin next to it.
